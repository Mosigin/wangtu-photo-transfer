# 验证矩阵

初始公开版本，2026-10-31。

| 项目 | 证据／边界 |
|---|---|
| 原始照片／Live导入引擎 | 既往Mac + 实际iPhone使用，含JPEG／PNG／HEIC和有效Live，保存后逐原资源读回；具体私人素材和设备编号不公开 |
| 公开泛化版 | 独立源码检查、规划和协议测试；**尚未重新安装到设备进行整套验证** |
| 视频原生保存／播放 | 代码已实现，纯逻辑和iOS源码检查；**待真机验收** |
| 大视频批次 | 自动测试覆盖大于1GB视频独立成批、临时双份空间不足时不发送 |
| 目录与清单 | 自动测试：递归同名隔离、相对路径边界、仅照片／仅视频、显式Live、禁止重复资源、日期时区 |
| 回执与恢复 | 自动测试：错批次／错资产／缺失回执拒绝、空间处部分结果、原子账本、读状态瞬断有界重试 |
| 手机规则 | Swift可执行检查：资源组合、视频单资源、拒绝错误组合、路径／schema／空间边界、停止状态保持 |
| Windows | 规划和协议用例已配置CI，实际结果以仓库Checks为准；**没有Windows + iPhone USB实测** |
| 图标和资源 | 无文字1024×1024图标，独立中英界面／权限来源及工程引用检查 |

CI通过不等于安装成功、Photos保存成功或视频可播放。验收新平台时保存工具commit、系统和格式类型、成功／失败／未知项及实际剩余空间；不要提交原媒体、账号、设备ID、描述文件或本机路径。
